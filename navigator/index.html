Foundation 04 · 05

When the local best is not the whole best

The Boundary Divergence Index asks if the action a local actor prefers differs from the one the full consequential system prefers.

BDI = J_G(a*_S) − J_G(a*_G) ≥ 0

BDI = 0

Optima agree. Output: NO ACTIVATION. Do nothing special.

BDI > 0

The local winner costs the wider system. Trace the displacement and find who carries it.

Schema gap

Representation failure is not evidence that the unrepresented state is zero. What a receiver can’t see still exists.

Foundation 19

Four honest outputs

NO ACTIVATION

Local and whole-system optima don’t materially diverge.

UNKNOWN

The consequential effect can’t be identified from the available evidence.

NO FEASIBLE MU+

Displacement is real, but no feasible build clears every protected carrier.

MU+ PASS

A preregistered construction clears thresholds, safety, concentration and reserve gates.

Reserve / Value Gap

RVGⱼ = ιⱼ − αⱼ

A system can look stable because a hidden reserve, caregiver or future self is compensating. RVG makes that visible: incoming burden minus absorption capacity.

Cost of truth

K_T(q,t) > R_G(t) ⇒ build first

A true statement can still overload a system not yet ready to absorb it. The answer is phased construction, not indefinite suppression.

Illustrative applications

Real-world examples

My own plain-language readings of how the grammar would apply. Each is a worked intuition rather than a result from the book.

Caregiving · Adapter 007

The hospital discharge

A hospital cuts length of stay to hit its local KPI. The cost doesn’t vanish: it lands on a family caregiver who now has to cover wound care and lost wages. LERM names the caregiver as carrier C*; IAMF-P builds home-care support before discharge; the RVG shows the hidden reserve being drained.

Luxury goods · Adapter 043

Resale and value preservation

A brand optimizes new-sales revenue. The schema can’t see authenticated resale, repair or lifecycle value, so a whole carrier (owners holding the goods) is invisible. Capacity built before a policy change, such as authentication and reconciliation records, keeps that value from being treated as zero.

Banking · Adapter 053

A branch closure

Closing branches improves the bank’s cost ratio (local optimum). Rural elders and small merchants carry the cost as travel time and cash access. BDI > 0; the build is agent-banking points and phased closure with retests.

Education · Adapter 032

Test-score targets

A school lifts averages by focusing on borderline students. The score schema doesn’t record who was dropped from attention. Carrier-level gates require each group to clear its own threshold.

AI · Adapter 061

Automated moderation

A model reduces average error. Minority-language users absorb the false positives. Per-carrier thresholds replace the single accuracy number.

Climate · Adapter 079

A flood wall

A wall protects the city centre and pushes water to downstream farms. The build includes retention areas and compensation before the wall is released.

Negatives retained

In a 250,000-case routing ablation, full telemetry cut burden 2.22% against 1.62% for LERM/IAMF-P. The book keeps that loss on the record.

Corrected run (exploratory)

After building capacity at the predicted loss carrier: 5.67% vs 5.56%, roughly a 2% relative edge. Because the semantics changed after the failure, it is exploratory.

Universality ≠ one action

In a 1M-system test a generic frozen action won only 1 of 20 domains. What’s universal is the grammar, not the move.

Falsification. Freeze the kernel, boundary, comparator, information budget and horizon before outcomes. Predict the carrier on untouched data. The programme weakens if carrier prediction doesn’t beat comparators or if MU+ repeatedly fails despite a feasible build.

Adapter 043 · Family 5 · Luxury goods

Governed luxury access and authenticated circular luxury

Local action: the mean rises from 62.0 to 64.3 and looks fine, but Carrier B falls 67 → 61. IAMF-P gives up some of A’s gain (58 instead of 61), and B reaches 74 while C reaches 73.

1 · Native systemState: provenance, scarcity, condition, access, identity, inventory and lifecycle value. Carriers: buyer, seller, inventory, environment. Position: origin-business fit.
2 · TopologyThe incumbent sees a price/status/authenticity binary. Brand or access value can shift waste, capital lockup or trust burden onto another carrier.
3 · LanguageΣ = price/status/authenticity binary. Blocker B = value shifted into waste, lockup or trust burden. ΔR* = provenance + condition + access + reconciliation layer.
4 · NumbersSee the chart: A 50/61/58, B 67/61/74, C 69/71/73 for baseline, local and IAMF-P.
5 · TimelineObserve the state, propose via the binary, predict the displacement, build the reconciliation layer before release, transition, retest value retention, trust, access and waste, then recur.
6 · EvidenceClosest to the discovery record, so independence from the origin is the first test. Decisive design: an operational field study. Strong evidence needs sealed carrier prediction and independent replication.
7 · NextFreeze the boundary and carriers, write the incumbent schema exactly, check BDI, specify the smallest feasible build, accept only if value retention, trust, access and waste all improve, and publish failed alternatives.
Adapter 120 · Family 12 · Meta-adapter

Cross-substrate consciousness, temporal coexistence and closure

Local action: the mean is nearly flat (58.0 → 58.7), yet B falls 64 → 59 and C falls 50 → 49. The IAMF-P action lifts all three: 65, 68 and 53.

1 · Native systemState: the whole coupled state across Adapters 001–119, with dependencies, horizons and consciousness-legibility. Carriers: all materially coupled conscious carriers, through direct, indirect and delayed paths.
2 · TopologyThe incumbent is any adapter, species, institution or observer claiming closure from its own schema alone.
3 · LanguageBlocker B: a new truth, capability or optimization is locally beneficial while dependent carriers lack the capacity to absorb it through time.
4 · NumbersSee the chart: A 60/68/65, B 64/59/68, C 50/49/53.
5 · TimelineCapacity is built across relevant adapters before release and phased through time, and the post-state feeds the next state so newly visible burden is never discarded.
6 · EvidenceStatus: meta-adapter, requires domain-native validation. Decisive design: a time-locked system-of-systems closure test across multiple adapters.
7 · NextThe same nine steps, run across adapters at once: freeze, model, check BDI, trace carriers, build the smallest feasible capacity, retain negatives and UNKNOWN, accept only on MU+.

How to use it

Freeze the boundary, horizon, protected carriers and comparator before seeing outcomes.
Map the native state and write the incumbent schema exactly as it exists.
Check BDI. If local and whole optima don’t diverge, return NO ACTIVATION.
Trace carriers, couplings and hidden compensators, then estimate displacement.
Build the missing capacity before the transition is released.
Act and retest until every carrier passes MU+.
